# 我的 Codex 使用问题记录

我在这个仓库记录自己使用 Codex 桌面应用时遇到的 bug、异常现象和排查结果，希望同样遇到问题的人能够找到有用的线索，也方便向开发者描述问题。

我会尽量写清楚：当时发生了什么、我期望怎样、实际报了什么错误、有哪些直接证据、尝试过哪些办法，以及最后有没有真正恢复。没有验证的推测会明确标出，不把一次尝试当作修复成功。

这是个人使用记录。条目中的“本机已恢复”表示我的环境通过了验收，不表示官方已经修复，也不保证其他版本或电脑会得到相同结果。

## 我希望这些记录能帮助解决什么

这次最让我困惑的是：浏览器窗口能打开、网页内容能传到对话，设置里也显示扩展已安装，但自动控制只给出 `Browser is not available`。真正的配置读取错误没有直接呈现在用户可见的位置。

我希望后续诊断能够指出具体失败环节，例如配置路径被拒绝、通信宿主缺失或会话连接失败，而不是让用户不断重启、重装或更换网络。

## 如何继续记录

后续问题可以使用本仓库的 [Issue 模板](.github/ISSUE_TEMPLATE/bug-report.md)，记录版本、复现条件、实际结果和证据。需要长期保留的条目放在 `reports/`，同时更新上面的目录。

我会区分“未解决”“原因待确认”“本机已恢复”和“官方已确认修复”。只有实际完成页面读取、输入或点击等相应功能验收，才会将本机状态改为已恢复。
